# 多机器人测试模式操作

> 历史文档：本文描述的是早期固定动作测试，不适用于 `simple1` 三阶段围捕。
> 当前实机流程、角色规则与全局安全停止策略请以
> [`TEST_MODE.md`](TEST_MODE.md) 为准。

## 使用前安全检查

1. 第一次测试时架空所有机器人轮子。
2. 确认 USB 接收器已连接，界面能看到机器人反馈。
3. 保证机器人周围有足够空间，并让物理断电手段保持可达。
4. 先测试一台机器人，确认左右轮方向，再测试两台和全部机器人。

## 界面操作

- 点击“开始测试”后，系统快照当前在线且已激活的全部机器人，并同步执行一轮固定动作。
- 测试开始后才上线的机器人不会加入本轮动作。
- 点击“停止”会禁止后续非零命令，并连续发送三轮零速。
- 出现接收器错误或掉线提示时，需要现场确认相应机器人已经停止。

## 固定动作

| 阶段 | 左轮 | 右轮 | 时间 |
|---|---:|---:|---:|
| 前进 | +200 | +200 | 2 秒 |
| 停止 | 0 | 0 | 1 秒 |
| 左转 | -150 | +150 | 2 秒 |
| 停止 | 0 | 0 | 1 秒 |
| 右转 | +150 | -150 | 2 秒 |
| 停止 | 0 | 0 | 1 秒 |
| 后退 | -200 | -200 | 2 秒 |
| 最终停止 | 0 | 0 | 连续 3 个发送周期 |

每次点击只执行一轮，不会自动循环。

## 串口速度说明

界面和状态机使用的轮速范围是 `-1000` 到 `+1000`。串口负载中的 `positionX` 和 `positionY` 使用 Zooid 固件偏置编码：

```text
encodedSpeed = wheelSpeed + 2000 + 7
```

因此零速在串口负载中是 `2007`，不是字面值 `0`。例如：

- `+200` 编码为 `2207`
- `-150` 编码为 `1857`
- `0` 编码为 `2007`

USB 外层帧保持：

```text
0x7E | 0x06 | 接收器内机器人ID | 负载长度 | PositionControlMessage | 0x21
```

全局机器人 ID 按每个接收器 10 台进行路由：接收器编号为 `globalId / 10`，接收器内 ID 为 `globalId % 10`。

## 分阶段验收

- [ ] 单台机器人架空轮子，方向与动作表一致。
- [ ] 单台机器人落地，在每个非零阶段测试“停止”。
- [ ] 两台机器人同步运动，且 ID 路由互不串扰。
- [ ] 全部机器人同步完成一轮，后上线机器人保持静止。
- [ ] 测试中断开一台机器人，其余机器人继续且界面显示掉线 ID。
- [ ] 接收器发送失败时，界面显示错误并进入安全停止。
- [ ] 运动中关闭程序时，可通信机器人在串口关闭前收到零速。
